# বাংলা বিএসটিআই মোবাইল কীবোর্ড লে-আউট (Bangla BSTI Mobile)

> জাতীয় কীবোর্ড (সংশোধিত) BDS 1738:2018-এর ওপর ভিত্তি করে এবং মোবাইল টাইপিংয়-এ পূর্ণ স্বাচ্ছন্দ্য আনার উপযোগী করে তৈরীকৃত লে-আউট।

**Bangla BSTI Mobile** হলো বাংলাদেশ স্ট্যান্ডার্ডস অ্যান্ড টেস্টিং ইনস্টিটিউশন (BSTI) অনুমোদিত জাতীয় কীবোর্ড (সংশোধিত) **BDS 1738:2018**-এর ওপর ভিত্তি করে তৈরি একটি বিশেষ বাংলা মোবাইল কীবোর্ড লে-আউট। প্রচলিত ডেস্কটপ লে-আউটের মূল ব্যঞ্জনবর্ণের ভিত্তি অক্ষুণ্ণ রেখে Touchscreen উপযোগী প্রয়োজনীয় আধুনিক পরিবর্তন আনা হয়েছে—যার মধ্যে রয়েছে সরাসরি লং-প্রেসে পূর্ণাঙ্গ স্বরবর্ণ টাইপ, শিফট স্তরে একক লং-প্রেস ওভারলেতে দ্রুত জটিল যুক্তাক্ষর ইনপুট এবং পরিচ্ছন্ন লং-প্রেস বিন্যাস।

## 🚀 ব্যবহারিক সুবিধা ও উন্নয়নসমূহ (Key Usability Enhancements)

1. **যৌক্তিক ইউনিকোড ইনপুট (Logical Unicode Input Order):**
   * BDS 1738:2018-এর ডেস্কটপ নীতিমালায় ঐতিহ্যবাহী টাইপরাইটার ও প্রি-ইউনিকোড লে-আউটের (যেমন: বিজয়) মতো দৃশ্যমান টাইপিং ক্রম রাখা হয়েছিলো, যেখানে ব্যঞ্জনবর্ণের আগে কার-চিহ্ন টাইপ করতে হতো (যেমন: `ে` + `ক` + `া` = `কো`)। এটি ইউনিকোডের মূল ফোনেটিক ও লজিক্যাল রীতির পরিপন্থী। **Bangla BSTI Mobile**-এ সম্পূর্ণরূপে প্রমিত ইউনিকোড ক্রম অনুসরণ করা হয়েছে: **ব্যঞ্জনবর্ণ + কার-চিহ্ন** (যেমন: `ক` + `ো` = `কো`)।
2. **ডেস্কটপ জটিলতার বিপরীতে স্বজ্ঞাত লং-প্রেস স্বরবর্ণ:**
   * ফিজিক্যাল কীবোর্ডে টাইপরাইটার ধারার শর্টকাট (যেমন: `্` + `ে` = `এ`) সুবিধাজনক হলেও মোবাইল টাচস্ক্রিনে এমন মাল্টি-ট্যাপ সিকোয়েন্স অত্যন্ত ধীরগতির, সময়সাপেক্ষ ও ভুলপ্রবণ। তাই টাইপিং গতি বাড়াতে সংশ্লিষ্ট কার-চিহ্নের লং-প্রেসে সরাসরি মূল স্বরবর্ণ যুক্ত করা হয়েছে। যেমন: `া` চেপে রাখলে `আ`, `ি` চেপে রাখলে `ই`, `ে` চেপে রাখলে `এ`, এবং `ো` চেপে রাখলে `ও` পাওয়া যায়।
3. **সহজ টাইপিংয়ের জন্য রেডিমেড যুক্তাক্ষর ওভারলে:**
   * হসন্ত দিয়ে যুক্তাক্ষর লিখতে ব্যাকরণগত বিশ্লিষ্ট রূপের সুস্পষ্ট ধারণা থাকা প্রয়োজন (যেমন: `ক` + `্` + `ষ` = `ক্ষ` বা `জ` + `্` + `ঞ` = `জ্ঞ`), যা সাধারণ মোবাইল ব্যবহারকারীদের জন্য অনেক সময় জটিল। এই বাধা দূর করতে বহুল ব্যবহৃত জটিল যুক্তাক্ষরগুলো (যেমন: ঙ্ক, ঞ্চ, ঞ্জ, জ্ঞ, ঙ্গ, ক্ষ, ষ্ণ, হ্ম, ব়্য) শিফট স্তরের প্রাসঙ্গিক কী-এর লং-প্রেস ওভারলেতে সরাসরি যুক্ত করা হয়েছে।
4. **ও-কার (`ো`) এবং ঔ-কার (`ৌ`)-এর একক কী বিন্যাস:**
   * দুটি আলাদা কার-চিহ্ন চাপার ঝামেলা এড়াতে মূল লেয়ারের `X` কিতে সরাসরি ও-কার (`ো`) (লং-প্রেসে `ও`) এবং শিফট লেয়ারে `Shift + X`-এ সরাসরি ঔ-কার (`ৌ`) (লং-প্রেসে `ঔ`) রাখা হয়েছে।

## 📝 স্বাধীন স্বরবর্ণ লেখার নিয়ম (Independent Vowels)

সহজ লং-প্রেস ওভারলে ব্যবহার করে স্বাধীন স্বরবর্ণগুলো টাইপ করা যায়:

- **অ:** সরাসরি `Shift + F` (`U+0985`)
- **আ:** `f` (`া`)-এর লং-প্রেস (`U+0986`)
- **ই:** `d` (`ি`)-এর লং-প্রেস (`U+0987`)
- **ঈ:** `Shift + D` (`ী`)-এর লং-প্রেস (`U+0988`)
- **উ:** `s` (`ু`)-এর লং-প্রেস (`U+0989`)
- **ঊ:** `Shift + S` (`ূ`)-এর লং-প্রেস (`U+098A`)
- **ঋ:** `a` (`ৃ`)-এর লং-প্রেস (`U+098B`)
- **এ:** `c` (`ে`)-এর লং-প্রেস (`U+098F`)
- **ঐ:** `Shift + C` (`ৈ`)-এর লং-প্রেস (`U+0990`)
